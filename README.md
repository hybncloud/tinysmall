## 🛠️ 如何使用

### 1. 安装

执行以下命令，安装 TinySmall 组件库：

```shell
npm i tinysmall
```

### 2. 引入和使用

在`App.vue`文件中使用 TinyVue 组件。

```html
<script lang="ts" setup>
  import { TinyButton } from 'tinysmall'
</script>

<template>
  <TinyButton>TinySmall</TinyButton>
</template>
```
